Entertainment and USB audio — actual bench check, 2026-11-13
Firmware55.00.750B/NA; native original and Snap JS remain installed/loaded.

RESULT
One ordinary Home->LEFT->ENTER sequence reproduced the failure. Synthetic Linux
evdev input, not physical commander: native SelectEntertainment reached system
HomeScreen. Current/previous/lastBroadcast sources unavailable; fallback fmradio
was refused by the audio source manager: 'Audio is not enabled'. After-photo
shows Home with Entertainment highlighted, no audio screen. This is not a broken
icon/click handler. No installed-file, routing, driver/service change or reboot.

Latest recorded Snap boot separately reports 'Tau is disconnected!', 'Tau
connected timeout!', 'TAU is not ready yet!' and native 'Audio is Disabled'.
Exact saved native code links audio-manager connection/notification callbacks to
StatusUpdateAudioEnabled1479 and the native audio-source manager boolean.
This strongly implicates missing TAU readiness, but is not exhaustive proof of
every downstream dependency. No simple standalone setting established.

USB HEADPHONE ADAPTER
Fresh /proc/modules confirms snd_usb_audio ALREADY loaded. Its .ko is installed;
aplay and amixer exist. /proc/asound/cards currently lists only built-in
aic310x-audio (card0) and wl1285q-audio (card1); no USB DAC tested.
Installed /etc/asound.conf routes entertainmentUsb (USB media INPUT) through
softvol/mux/asymed/dmix to hw:0,0. It is not a USB sound-card OUTPUT setting.
A compatible USB DAC could plausibly support direct ALSA playback; automatic
Mazda routing and Entertainment readiness do not follow from driver presence.
Do not replace the complete audio config just to test direct PCM playback.

RECOMMENDATION
Use a compatible real TAU and documented bench wiring for realistic audio,
source-resume and CarPlay tests. Resolve exact CMU/TAU compatibility before any
purchase. No emulator or synthetic ready-state workaround currently justified.
USB DAC is a separate inexpensive experiment once physically available: enumerate
the actual card, then bounded direct low-level playback before considering routing.
User permits judgment: easy clean tuner-free route welcome; otherwise real TAU.
