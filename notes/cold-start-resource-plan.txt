under the same unit/firmware, phone/OS, adapter/version, pairing/media/SD and power
conditions. The user's car need not match this stock55 bench. Shipping hardware

failure stage/times: UI-ready -> BT -> Wi-Fi -> CarPlay -> usable session, plus
disconnect/retry count. Delayed success alone is not proof of RAM as root cause.

spoof heartbeat, create a daemon/schedule, change firmware or request user actions.
