# Historical records

Dated research, observations and superseded plans retained for provenance.
These are not setup instructions, deployment packages or current device state.
The useful entry point is [Mazda findings](../reverse-engineering.md).

Former notes/ observations now live directly here. The former research/ catalog
is under catalog/; former examples/ UART calibration records are under uart/.
Those were evidence records, not runnable examples. tools/ holds retired scripts.

Old records retain the paths, hashes and descriptions from their original runs.
Use Git history to recover that exact tree; do not rewrite old evidence to imply
it was produced by today's code. Private captures remain outside the public repo.

On the original lab checkout, leftover private research/example captures were
moved intact to .local/legacy/ under their former directory names.
