What was useful

markers, unknown-on-timeout and preserved RX made diagnosis/recovery possible.

and research/code history remain available. Those controls should stay.

Changes to how I coordinate
1. Assign one complete bounded work package with stop conditions, rather than
   repeatedly authorizing routine steps already within that package.
2. Reproduce with the smallest inert input, patch, run relevant tests and one
   scoped review, then get the live result. Archive/index after the result.
3. Pin an accepted code profile once; avoid repeated full-source audits per
   transaction. Report a compact measured result before generating summaries.
4. Distinguish transport/content success from wrapper/framing fixture defects.
   Preserve both original reports; validate the tagged payload and known framing.
5. Stop new experiments when asked for a retrospective. Leave the bench at a
   known state, with handles closed and a concrete next step.
